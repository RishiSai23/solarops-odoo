# SolarOps — Frontend

## Status & Purpose

The `frontend/` directory is currently reserved for future architectural extensions. 

### Current Application Architecture

The active implementation of SolarOps is built entirely as a **native Odoo 17 modular application** located in `backend/`. Odoo provides its own integrated web client, responsive form/list/kanban interfaces, and standard web controllers.

### Future Scope

If a custom customer portal, dedicated installer mobile application, or customer-facing quotation portal (e.g., using a modern JavaScript/TypeScript framework) is introduced in subsequent phases, its codebase and build pipeline will reside within this directory.

No frontend implementation is required or active for Module 1.
